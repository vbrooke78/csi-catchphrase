# CSI Catchphrase

A small React game built with Vite. Players can navigate between a home screen, a question page, and the catchphrase game board, with routing provided by React Router.

## Key features

- React 18 app powered by Vite
- Client-side navigation via `react-router-dom`
- Game flow split into reusable components under `src/components`
- Question data organized in `src/data`
- Production-ready build output in the `dist/` folder

## Tech stack

- React
- React Router DOM
- Vite
- JavaScript
- CSS modules and static assets

## Getting started

### Prerequisites

- Node.js (recommended 18+)
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

Open `http://localhost:5173` in your browser.

### Build for production

```bash
npm run build
```

This creates an optimized production build in the `dist/` directory.

## Useful scripts

- `npm start` - development server
- `npm run dev` - development server alias
- `npm run build` - production build
- `npm run preview` - locally preview production build
