# CSI Catchphrase

A small React game built with Create React App. Players can navigate between a home screen, a question page, and the catchphrase game board, with routing provided by React Router.

## Key features

- React 18 app powered by Create React App
- Client-side navigation via `react-router-dom`
- Game flow split into reusable components under `src/components`
- Question data organized in `src/data`
- Production-ready build output in the `build/` folder

## Tech stack

- React
- React Router DOM
- Create React App
- JavaScript
- CSS modules and static assets

## Getting started

### Prerequisites

- Node.js (recommended 18+)
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

Open `http://localhost:3000` in your browser.

### Build for production

```bash
npm run build
```

This creates an optimized production build in the `build/` directory.

## Useful scripts

- `npm start` - development server
- `npm run build` - production build
- `npm test` - run tests
- `npm run eject` - eject CRA configuration
